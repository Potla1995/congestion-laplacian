# Vertex congestion bounds using Laplacian eigenvalues and their application to tensor networks with arbitrary geometry
## Sayan Mukherjee, Shinichiro Akiyama
This repository contains code used to generate the results in the original manuscript.

### Prerequisites
Installation of the following python libraries are required to run this code:
`scipy`, `matplotlib`, `networkx`, `joblib`, `qiskit`.

### Code Structure
- `circuitutils.py` contains utility functions for converting quantum circuits to their graph representations.
- `contractiontree.py` contains utility functions for storing contraction trees (an embedding of a base graph into a rooted binary tree).
- `spectralutils.py` contains utility functions for the hierarchical spectral clustering algorithm, and other relevant graph spectrum code.
- `experiments.py` contains parallel code for our numerical (random) experiments. Each experiment generates a `csv` file in the `output` directory.
- `plot_lattice.py` contains code for our numerical experiments on the rectangular lattice graphs.
- `plot.py` contains functions for plotting the `csv` files generated by our code.
- `main.py` has code for running the experiments.

### Instructions for Running the Code
- Clone this repository via `git clone` and install required libraries using `pip` or `conda`,
- Simply uncomment the relevant lines in `main.py` and run the relevant experiments. Output will be generated in the `output` directory.
- To plot the outputs, run `plot.py`.
- To perform the lattice experiments, run `plot_lattice.py`.
- All plots are generated as `pdf` files in the `output` directory.
- The data obtained by this code, along with the `csv` files is in the `output/` directory
